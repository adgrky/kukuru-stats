Privacy Policy — kukuru-stats

Last updated: 2026-11-09

What this tool is

kukuru-stats is a private tool used only by the owner of the YouTube channels "Kukuru's Wonder World Japan" and "El Japón Escondido de Kukuru" to review the performance of their own videos.

Data accessed

With the owner's permission, the tool uses youtube.readonly, yt-analytics.readonly and youtube.force-ssl to read: the channel's video list, YouTube Analytics reports for those videos, and comments on those videos. The youtube.force-ssl permission is used to read comments and, only when the owner explicitly approves each action, to reply to or moderate comments on the owner's own videos. The tool does not upload, edit, or delete videos.

How data is used and stored

  • Data is used only to create performance reports for the channel owner.
  • Data and access tokens are stored only on the owner's own computer and private storage.
  • Data is not sold, shared with, or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

kukuru-stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
